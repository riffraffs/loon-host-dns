# Loon Host DNS 映射

可订阅的 Loon 插件。在 `[Host]` 里按域名指定 DNS 服务器，不是把域名解析成固定 IP。

## 订阅

在 Loon 里打开「配置 → 插件」，点右上角添加，选「订阅插件」，粘贴：

```
https://raw.githubusercontent.com/riffraffs/loon-host-dns/main/Host-DNS.plugin
```

## DNS

| 分组 | 服务器 |
| --- | --- |
| TestFlight | `8.8.4.4` |
| Apple 国内、阿里、美团 | `223.5.5.5`（阿里 DNS） |
| 腾讯、哔哩哔哩、咪咕、比亚迪 | `119.29.29.29`（腾讯 DNS） |

`*.weixin.qq.com.cn` 按你给的域名保留。
